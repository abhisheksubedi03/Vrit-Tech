# Drag-and-Drop Kanban Board

## Setup Instructions
1. Clone the repository:  
   `git clone <repo-url>`
2. Install dependencies:  
   `npm install`
3. Run the development server:  
   `npm start`
4. Open your browser and go to `http://localhost:3000`

## Technology Choices and Rationale
- **React**: Flexible and efficient UI library for building interactive UIs.
- **react-beautiful-dnd**: Provides easy drag-and-drop functionality with smooth animations.
- **TypeScript**: Ensures type safety and helps avoid potential runtime errors.
- **Local Storage**: To persist tasks and columns data across page reloads.

## Known Limitations/Trade-offs
- Limited browser support for drag-and-drop in older versions of Internet Explorer.
- Performance might degrade with a large number of tasks due to lack of optimization.

## Future Improvements
- Improve performance for large task lists (e.g., virtualized rendering).
- Add user authentication and cloud storage for persistent data across devices.
